Quick Buy 🛒

Quick Buy is a full-stack e-commerce web application built using the MERN stack.
The application supports role-based access for customers and sellers, enabling seamless product management and online shopping experiences.

🚀 Features
Customer

Browse products

Add products to cart

Place orders

Secure authentication

Seller

Add, update, and delete products

Manage inventory

View listed products

General

JWT-based authentication

Role-based authorization (Customer / Seller)

Responsive UI

Secure RESTful APIs

🏗️ Application Architecture

Frontend

React-based UI

Client-side routing

API integration using Axios

Backend

RESTful API design

Authentication & authorization using JWT

Secure handling of user roles

Modular route and controller structure

Database

MongoDB collections for users, products, and orders

🔐 Authentication & Authorization Flow

User registers / logs in

Server generates a JWT token

Token is used to authenticate API requests

Role-based access controls available endpoints



🧪 How to Run Locally
Backend
cd backend
npm install
npm start

Frontend
cd frontend
npm install
npm start


Make sure MongoDB is running locally or update the MongoDB connection string.
